# Etapa 1 de 5 — GitHub

**Objetivo desta etapa:** ter a sua própria cópia do Cérebro CRM,
pronta para ser publicada nas próximas etapas.

**Tempo estimado:** 10 minutos.

## O que é o GitHub, em uma frase

O GitHub é onde o código deste CRM mora. Pense nele como um "Google
Drive para código": o projeto inteiro está guardado lá, e você vai
fazer uma cópia dele — chamada de **fork** — na sua própria conta,
para poder publicar essa cópia depois.

Você não vai escrever nem editar nenhum código nesta etapa. Só vai
criar uma conta e clicar em um botão.

## Passo 1 — Criar uma conta no GitHub

1. Acesse **[github.com](https://github.com)**.
2. No canto superior direito, clique em **Sign up** (Cadastrar-se).
3. Preencha:
   - Seu e-mail.
   - Uma senha (anote no seu bloco de notas).
   - Um **nome de usuário** — escolha algo profissional, sem espaços
     (ex: `advmoacirmariz` em vez de `Moacir Mariz Advogado`). Esse
     nome vai aparecer no endereço do seu projeto depois.
4. O GitHub vai pedir para confirmar que você não é um robô (alguma
   verificação simples de imagem ou clique) e depois enviar um código
   para o seu e-mail. Abra seu e-mail, copie o código, cole na tela do
   GitHub.
5. Pronto — sua conta está criada. Pode pular as telas de
   "personalização" que aparecem em seguida (perguntas sobre time,
   experiência, etc.) clicando em **Skip** (Pular) se preferir.

> 💡 Se você já tem uma conta no GitHub (por exemplo, criada em algum
> momento por curiosidade), pode reaproveitá-la — não precisa criar
> uma nova.

## Passo 2 — Fazer o "fork" do projeto

**Fork** é o botão que cria a sua própria cópia de um projeto. A
cópia fica ligada ao original (você pode saber se o original recebeu
atualizações), mas é totalmente sua — você decide o que fazer com
ela.

1. Com você já logado no GitHub, acesse:
   **[github.com/advmoacirmariz-blip/crm-aberto](https://github.com/advmoacirmariz-blip/crm-aberto)**
2. No canto superior direito da página, clique no botão **Fork**
   (tem um ícone parecido com um garfo/bifurcação, ao lado de
   **Star**).
3. O GitHub abre uma tela de confirmação:
   - **Owner** (Dono): deixe selecionado o seu próprio usuário.
   - **Repository name** (Nome do repositório): pode deixar o padrão
     `crm-aberto`, ou trocar por outro nome se preferir (ex:
     `crm-do-meu-escritorio`). Sem espaços, sem acentos.
   - **Description**: opcional, pode deixar em branco.
   - A opção **Copy the `main` branch only** pode ficar marcada
     (padrão).
4. Clique no botão verde **Create fork**.
5. Espere alguns segundos — o GitHub vai te levar para a página da
   sua própria cópia do projeto, em um endereço como:
   `github.com/SEU-USUARIO/crm-aberto`

## Passo 3 — Confirme que deu certo

Olhe para o canto superior esquerdo da página que abriu. Deve
aparecer algo como:

```
SEU-USUARIO / crm-aberto
forked from advmoacirmariz-blip/crm-aberto
```

Se está assim, deu tudo certo — você agora tem sua própria cópia
completa do projeto no GitHub.

## ✅ Checklist ao final desta etapa

Anote no seu bloco de notas:

- [ ] Endereço da sua cópia do projeto:
      `https://github.com/SEU-USUARIO/crm-aberto`
- [ ] Usuário e senha do GitHub (ou confirme que está usando um
      gerenciador de senhas)

## Problemas comuns

- **"Não recebi o e-mail de confirmação do GitHub"** — confira a caixa
  de spam/lixo eletrônico. Pode levar 1–2 minutos.
- **"O botão Fork está cinza/desabilitado"** — normalmente significa
  que você já tem um fork desse projeto na sua conta. Role a página
  até o final, ou procure em `github.com/SEU-USUARIO/crm-aberto` — ele
  já pode existir.
- **"Apareceu uma tela pedindo para escolher uma organização"** — se
  você só tem sua conta pessoal, ela já vem selecionada por padrão;
  pode seguir em frente.
